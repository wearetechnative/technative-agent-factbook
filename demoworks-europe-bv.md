# DemoWorks Europe BV — Factsheet

> **Mockup / demo company.** DemoWorks Europe BV is a fictional company used by
> TechNative as the canonical stand-in for a managed-service customer. It exists
> so we can produce demo material — proposals, SLAs, Well-Architected reports,
> slides — without exposing real customer data. All "facts" about DemoWorks are
> invented but kept internally consistent across our demo repositories.
>
> **This file is the single source of truth for DemoWorks facts.** When demo
> material needs a DemoWorks detail, take it from here. Nothing here refers to a
> real organisation; email/domain placeholders use the reserved `.example` TLD
> and AWS account IDs use obvious `1…/2…/3…` placeholders.
